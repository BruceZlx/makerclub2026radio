# 缺失输入清单

版本：v1.2 实施记录  
日期：2026-11-24

缺项不阻止 P2/P4/P5/P6 的独立逻辑开发，但会阻止对应硬件验收和最终发布。以下每一项都必须由真实材料或实测补齐，不能用猜测值、默认 GPIO、虚构地址或 mock 替代。

| 编号 | 缺失项 | 影响 | 解除条件 |
| --- | --- | --- | --- |
| I01 | partner 完整播放器源码、构建脚本、依赖副本 | 无法封装真实播放 API，无法证明单城成果被复用 | 接收源码、库副本、构建脚本与校验值，完成 M0 冒烟 |
| I02 | 完整 8 城表（稳定 id/code、顺序、坐标、台名、时区、文案） | 正式配置无法通过严格校验 | 内容组交付并逐项核对 |
| I03 | 16 条真实主备 URL 与逐源记录 | 无法执行 T08–T11、T22 | 每条记录日期、网络、目标板/软件版本、最终 URL、编码、首播与持续时间 |
| I04 | 8 份合法离线音频及来源说明 | 无法执行离线循环与 T09、T12、T13 | 8 个 MP3、时长、码率、来源与使用说明 |
| I05 | 巴黎/开罗候选源重新验收 | 两城仍可能不可播 | 按同一标准完成主备各 20/5 分钟测试 |
| I06 | ESP32-S3 具体模组、Flash、QSPI/OPI PSRAM、分区、USB | 无法确定完整 FQBN 与构建参数 | 硬件组提供模组文字/原图与实际配置 |
| I07 | 板 B 屏幕、扫描方式、显示库 | 无法接入真实刷新驱动与测帧率/内存 | 确认型号、尺寸、色深、扫描与库版本 |
| I08 | 全部物理 IO 与本地硬件配置 | 硬件构建必须失败，不能采用默认 GPIO | 填写 `config/hardware_pins.local.h` 并核对电平/电源 |
| I09 | Arduino CLI、Arduino-ESP32 3.3.12、ESP32-audioI2S 4.0.1 | 无法执行 S3 真实编译与上传 | 安装锁定版本并保存 library.properties/压缩包 SHA256 |
| I10 | 实机、SD 卡、MAX98357、网络与示波/听音条件 | 无法执行 T01–T22 | 目标板与外设就绪，按矩阵逐项留证 |
| I11 | 2 小时活动模式/200 次混合操作与独立构建上传条件 | 无法完成 T19 与独立回归 | 实机长时间运行与另一成员独立构建上传 |
| I12 | 展示场地网络复测条件 | 无法确认现场可用性 | 在展示场地网络重新抽查主备与离线 |

## 当前结论

- 代码与主机验证可以继续推进。
- S3 编译、实机验收、T01–T22 与最终发布均保持 `BLOCKED`。
- 严格发布审核必须失败；不得把主机通过、预览生成或打包成功写成全部 P0 完成。
