## 4 使用边界

1. 诊断 demo 只用于网络诊断，不扩写为正式播放器，也不作为播放器重写依据。
2. 既有单城播放成果按 partner 确认记为已完成，但源码未接收前不得宣称已完成集成。
3. 主机测试、配置测试、显示预览和文档检查不能替代 S3 编译与实机验收。
4. 任何缺项都不得用默认 GPIO、虚构地址、音调或 mock 冒充。
